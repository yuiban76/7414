## 已接入的流程

- 柳津茶棚取得「茶棚裡的拳譜」傳聞，地圖會標出事件與相鄰路線。
- 朔京郊外可選擇接受口訣，或拒絕教學後以一次可重試的交鋒自行參悟。
- 八方拳承載「破勢連攻」：入門提高架勢傷害，成形後破勢追加一擊，大成後擊倒回內並追擊下一名敵人。
- 木樁試招、故地揚威與成名之戰使用固定事件 ID；勝負、重整、返回與讀檔不會重複發放唯一獎勵。
- 青衡山補全後可回柳津接戰帖，完成葉停舟成名之戰後取得「破陣客」稱號與江湖回應，並留下探索記事。
- 成名流程使用獨立 `world.zhaoye.journey` 狀態，不改寫八章主線的證據、生死、救援與政治旗標。
