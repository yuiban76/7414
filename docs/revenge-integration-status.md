# 十章復仇主線整合驗收 · 0.7.0

2026-11-15。使用者指示：「二十小時實測先不用，先接入遊戲並推送」。本輪發布範圍為十章作者稿接入單人遊戲；二十小時仍是設計目標，未作實測承諾。

## 0.7.1 修正紀錄

使用者回報第一場無法結束後，查出介面以 `round > null` 判斷無期限目標，導致必要的場景操作按鈕始終停用。原先的戰鬥模擬直接送出操作，沒有涵蓋這個介面阻斷，不能作為完整可玩性的證明。

修正後按鈕採用與目標提示相同的有限期限判斷；新增全部 29 種交鋒的實際按鈕輸出檢查，以及「師父已制伏、尚未接碗」存讀後從按鈕取得操作、完成戰鬥並推進正文的測試。完整測試為 231 項通過。存檔格式不變，0.7.0 卡住的戰鬥可續玩，無須重新開局。此回歸驗證為程式及 HTML 輸出測試，未宣稱完成真實瀏覽器操作。
