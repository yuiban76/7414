# 作者設定與連續性

## 固定事實

新故事發生在大寧，京城為定京。主角在照溪門練武十年，已有應敵根基。溫守拙是師父，始終保護遭禁武令追捕的人，沒有作惡、假死、附身或復活設定。第一章當夜死亡；此後出場只限明示的回憶。謝欣達下令滅門，衛峻領軍、洪百川供械、岳承義撤援、董綸調度。這些責任不同，不以一封口供全部證明。

謝欣達以禁武令要求門派交出武學、弟子入軍。他已經武功高強，不需要主角身上的神秘血脈、失傳神功或集齊信物。他要主角公開承認師父謀反，藉倖存弟子馴服其他門派。謝能犯錯，情報來自追蹤、軍報與主角公開行動，不具全知視角。

第十章謝欣達被主角斬殺，權力依靠傳令、軍械、部隊與官員運作；斬殺之前須由同伴及盟友實際破壞清剿部署。結尾沒有更大幕後魔王。

洪百川貪利且以工匠性命試械；殺手卞九只在安全距離動手；近衛韓逐鹿擅長短刃換手；許問針擅長封脈與逐步壓迫；董綸以安排別人赴死維持自己的安全。敵人不能全用同一種「先嘴硬、敗後交代下一人」結構。

## 地理與時間

照溪山 → 山下柳橋城 → 河梁洪家莊 → 松嶺岳家門庭 → 槐州謝府別院 → 白石鎮 → 西嶺霜草廬 → 北上軍運道 → 重門關 → 定京。

山門血夜在深秋；第五、六章入冬；第七章休養與練武跨過四十餘日；第八章雪融，第九、十章為早春。療傷、長途旅行需要正文過渡；沒有菜單等待時數。重門關在定京外，不是越過京城又折返。

## 選擇與缺席規則

每章至少一項抉擇改變路線、資源、援手或人物反應。分支可以匯合，但須演出差異與後果。選項後的正文分開書寫，不將未選經歷塞入共通段。

第八章程渡結果只有 `stay`（留隊）或 `leave`（離隊），不安排玩家處決。離隊後他不再參與九、十章隊內戰鬥；接應由第三章已登場的工匠閔石負責。程渡離隊結尾為自行投案及來信，不突返救場。沒有將兩條路線各自的功勞同時授予主角。

普通戰敗重試，不算永久命運；第六章是明示目標的突圍戰，完成突圍就算獲勝。師弟及陸見霜沒有強制死亡路線。本稿不接入舊版同伴、十二支線或政治證據系統。

## 終戰的可見因果

謝的定川訣以近身連壓逼敵追步；重掌連發後需收肩換氣，左肋短暫失守。第五章只見近衛讓位，第六章親受三步壓迫，第七章練能停住的腳步，第八章以戰例驗證「逼對手先收勢」。第十章先處理場地與連壓，再用已練過的方法進入破綻。不是得到臨時神功、喊出師父名字或怒氣暴增就取勝。
