# 《照夜行》十章完整作者稿

本目錄為全新創作的第三版完整作者稿，最終敵人為謝欣達，從照溪門日常寫至決戰、善後與重返山門。單一路徑正文已達十四至十八萬漢字預算，精確數量由檢查指令重算。已透過 `npm run story:export` 接入 0.7.0 十章遊戲／故事修訂 3。不要執行舊版 `npm run manuscript` 覆寫本稿。

## 閱讀順序

本目錄為完整版作者稿。遊戲 0.7.2 起預設使用 [精簡主線](../play-edition/README.md)，完整描寫改為每頁選讀；作者稿字數不是玩家必讀量。

可先直接閱讀移除作者註記的 [程渡留隊版](reading-stay.md) 或 [程渡離隊版](reading-leave.md)。以下分章原稿則保留所有選擇、條件與交鋒註記。

2. [雨巷追魂](02-雨巷追魂.md)
3. [血債山莊](03-血債山莊.md)
4. [義旗藏刃](04-義旗藏刃.md)

第二人稱「你」為可自訂姓名的主角。正文之外的選擇、交鋒與條件反應放在同場的作者註記；閱讀正文時可略過註記。條件段不能全部串讀為同一路徑。
