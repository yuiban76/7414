# 變更紀錄

## 2026-11-21 · 多人故事與記事（0.7.5）

- 在 WebRTC 房間加入戰鬥外的自由文字行動、AI 過場與可回查來源的記事。沿用原本的戰鬥、投票和分隊結算。
- 每次有效戰鬥行動保留原始紀錄，按已結算回合生成過場。投票生成過場前須先有系統結果。房主可暫停或重試模型，共同事件先保存並同步。
- 房間成員可下載共同記事，房主瀏覽器另外保存。新增多人測試，涵蓋正常結算、AI 阻塞與重試、重連及來源追溯。

## 2026-11-15 · 獨立 AI 自由故事模式（0.7.4）

- AI 故事改為首頁的獨立模式；移除原作章節中的 AI 改寫控制，不讀取、不改寫原作正文、選項、戰鬥或存檔。
- 新增 `docs/ai-story-outline.md` 作為 AI 模式專用大綱。玩家建立角色後，以自由文字輸入角色想做的事，模型依近期對話接續故事。
- AI 故事用白話繁體中文提示，並把角色、行動、回覆分回合保存在獨立瀏覽器存檔；離線快取包含故事大綱。
- 本機 AI 預設網址改為使用者提供的 `http://127.0.0.1:8686/v1`；仍可在設定自行調整網址、模型與選填 API Key。

## 2026-11-15 · 本機 AI 劇情正文版本（0.7.3）

- 十章一般閱讀頁可主動生成 AI 改寫正文，並在原作版與 AI 版間切換；未設定或未呼叫 AI 時，仍使用原作正文。
- AI 只改寫目前頁面的短正文，不改標題、選項、戰鬥、旗標、結局或遊戲存檔；提示內容以玩家已讀進度及目前路線作連續性背景。
- 設定頁提供 OpenAI 相容 API Base URL、模型、選填 API Key 與連線測試；AI 改寫結果暫存目前頁面，不寫入存檔。
