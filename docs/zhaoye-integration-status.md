- 64 個事件每個保留 A/B/C 三項選擇，並有獨立即時回話；主要分支接上新旗標。可逐項調查的入口不再互斥。
- 四條證據分未取得、待核對、已驗證；終局介面提前列出證據、支援與不足条件。舊案未提交時，不授予完整政治結局。三次救援損失僅加播追思，不蓋掉政治成果。
- 章末安全點、待履約返回入口、一次性章節獎勵、公共救援銀與私款分離。每次敘事操作都自動存檔。
- 十場主線交鋒有普通場景操作。操作在實際存活角色的行動順序中結算，不附送攻擊或防禦。陶安與信使的生死分開敘述；主鎖進度與六類指定損失鍵不重複累計。
- 新版境界不再按章節跳級，以實際武功、內功、經脈訓練計算。
- 離線殼列出全部静態模組，避免只缓存 app 入口；不刪除同源其他應用的快取。
- `tests/zhaoye.test.mjs` 與 `tests/zhaoye-invariants.test.mjs`：逐步序列化/還原、零錢、略過、全敗、終局條件、進度冪等、資訊不提前洩露、離線模組依賴等驗證。
- 瀏覽器已實際驗證創角、新劇情開場、讀檔恢復選後位置、兩組逐項調查，以及首場交鋒的場景行動消耗與紀錄。

- 2026-09-06：64 項測試通過。新版 28,800 場主線模擬通過可行性門檻；基準條件見腳本。單人初章救援負擔過高已調整，完整數值平衡與所有支線變體仍不能僅靠這個測試宣告完成。
- 後續投票修正：71 項測試通過。房間示範支援結算前改票、全員到票後過半、首次平票重投與再次平票裁決；2／1／1 不誤判多數。斷線等待 60 秒後排除缺席者選票，房主斷線暫停世界操作。這是房間層測試，不代表已接通多人主線。

- 封街護送修正：84 項測試通過。拆障通過街口後，仍需三次實際護送行動；擊倒賀嶠不自動完成運送，也不新增無限刷怪。弩射預告可先手控制／破勢打斷，拆障降低來襲壓力。戰敗必須完成第二路副本核封、護送、交接三步，進度可讀檔；延誤保留為下一章前哨支援減少，不刪除已驗證證據。這部分尚待瀏覽器全流程驗證。
- 行動結算、假旗戰、信使前哨與焚卷火場修正：104 項測試通過。藥品只在角色實際完成回合後扣除；先手擊倒角色不會消耗未執行的藥品，內力不足改用普通攻擊也不會增加武功熟練度。第五章新增重甲反擊／破勢解除護體／火盆擴散／卷宗出口與證人通道，未完成撤離時副卷可被焚失且會寫入章後狀態；第七章新增騎兵衝鋒／副絞盤／假旗軍令三段狀態，第八章新增快速連擊／射殺預告／信使保護；未核驗軍令不會假裝讓普通軍士停手，信使死亡仍保留封袋與命令，劇情結算會接收信使實際生死，所有狀態可讀檔恢復。

## 尚不可稱作完整劇本驗收通過

以下仍須逐項實作或取得更強證據，不可以用上面的通關測試代替：

1. 追加小選項、個人回話、多輪答辯已有獨立流程，但仍需核對全文、細緻回話與各自後果，不可宣稱完整逐句演出。
2. 五組短戰、切磋及三段家信已有流程，其餘擴寫事件的追逐／操作及變體仍須補齐與驗證；主線模擬不涵蓋這些短戰。
3. 章後返回履約目前使用一次交接操作；需要把要求具體行程、資源或補問的任務細化，並補齊所有原稿承諾及略過後果。
4. 助手分配僅有局部狀態。所有核心同伴在場/善後/護送的替代出演、具名接手與不重複占用還需要完整稽核。
5. 目前有一部分條件回收與準備效果；須逐項核對原稿每個選擇的章內代價、輔證來源、後章回收。不能把不同回話等同全部數值後果已生效。
6. 顧長纓及賀嶠已接入專屬階段／護送規則；其他主線 Boss 仍主要沿用既有戰鬥基礎數值與階段系統。原稿的分階段騎隊、弩陣、鹽塵、焚卷等仍須逐場實作驗證。已建立新版獨立平衡稽核，仍需補足狀態變體及支線戰覆蓋。
7. 房間目前仍是同機 BroadcastChannel 示範，沒有跨裝置後端，也未將整套新敘事接入權威世界同步。投票及斷線規則已有房間層修正，仍需多人瀏覽器驗證、接入主線及個人履歷，並補上中途加入與斷線戰鬥處理。
8. 尚須驗證全章瀏覽器互動、真實戰鬥存讀檔、匯出匯入新旗標、首次離線及手機尺寸。單元測試不能替代這些範圍。
