# 十章精簡主線 · 0.7.2

使用者回饋故事太冗長，玩家可能讀不下去。本次將必讀敘述與完整作者描寫分開，目標是讓因果清楚、轉折更快到達，不再以堆正文滿足二十小時目標。

## 改寫原則

- 全部402場逐場重寫，以具體動作、短對話、阻力與後果推進。刪去重複解釋同一道理的段落，保留師門日常中可回收的碗、棉布、收步與名字。
- 不截取每場前幾句，也不只列劇情摘要。原有選擇條件與共通段標記完整保留；人物知情、死亡、離隊與物件交接仍按原時序。
- 連續敘述最多合四場，最多600漢字；下一核心場景、重大選擇及尚未完成的交鋒各自停下，不能藉合頁略過。
- 每頁提供原生 `details/summary` 的「閱讀完整描寫（選讀）」，可用鍵盤展開。選讀不推進游標，未選的結果也不會提前顯示。介面沿用現有色彩及五個導覽入口。
- 戰前寫清現場與立即目標，校訂與正文不符的灰窯、掃帚陪練、渡亭伏擊、淺灘行船及危牆撤離；不更動戰鬥數值、模式、操作數量或獎勵。

## 資料與相容性

`01-03.json`、`04-06.json`、`07-09.json`、`10.json` 保存每場精簡正文；`encounter-leads.json` 保存戰前情境。`npm run story:export` 將它們與原稿一起匯入 `src/data/revenge-story.json`，不覆寫原稿。

場景ID、旗標、交鋒ID、獎勵與存檔格式不變。一次續頁會記錄該頁包含的全部事件；章末游標停在實際最後一場。0.7.0／0.7.1 的存檔即使停在合頁中間，也從原游標續讀，不強迫倒回開頭。已更正的交鋒名稱保留已知舊名相容驗證，不接受任意名稱。

235項完整測試通過，包含兩條十章代表路線逐步存讀、事件完整性、合頁邊界、重複點擊、第一戰及新版備份。時長實測依先前指示暫緩。UI搜尋未取得與選讀相符的資料庫建議，介面依通用鍵盤可及性與漸進揭露原則實作。
