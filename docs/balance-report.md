# V1 平衡檢查

## 平衡框架

- 類型：非對稱、情境式 PvE。
- 指標：教學戰可完成率、第一章 Boss 勝率、起始武功差距、平均回合數。
- 容許：合理配點與對應策略下，每個起始武功對第一章 Boss 勝率至少 55%；最高與最低差距不超過 40 個百分點。
- 刻意不平衡：攻擊型較快，防禦／控制／身法型以穩定性、情報與團隊價值換取較長回合。

## 發現與修正

1. Boss 人數傷害係數原先沒有接入最終傷害。已加入 `damageMultiplier` 並集中至 `balance.js`。
2. 破綻在被打出的同一回合結束就消失，慢速破勢角色無法讓隊友利用。已改為保留完整下一回合，結束後回復 30% 架勢。
3. 控制武功原本只有敘述、沒有戰鬥結果。現在控制攻擊會同步壓制敵方內力，敵人內力耗盡後退回普通攻擊。
4. 通用普通攻擊過弱，非攻擊起始武功形成死選項。基礎威力調為氣血 20／破勢 11，讓所有角色保有可靠的零內力輸出。
5. 陸小川錯配成衙門刀法。已依角色設定改用流雲劍與踏草步，讓他真正承擔劍術型隊友定位。

## 系統互動風險

- 破勢 → 破綻 → 1.5 倍氣血傷害是強正回饋，以只持續一回合及 30% 架勢復原控制。
- 多內功自然回氣採 3.0% 降至 2.0% 的負回饋，避免無限制疊加內力池與回復。
- 失敗不掉落資產，避免戰敗造成經濟死循環；Boss 情報保留，讓失敗轉化為知識資源。
- 八章重大旗標均有後續 `consumesFlags`；第七章集中回收前六章，第八章依旗標選擇最終敵人。

完整數值可重跑 `npm run balance`。報告以固定種子對每項起始武功執行 80 次模擬，可重現。
