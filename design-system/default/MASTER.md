# 江湖歸處設計系統

- 主題：夜墨案卷。深色環境承載紙張閱讀面，朱砂只標示重大選擇與危險，青玉表示可用與恢復。
- 色彩：夜墨 `#111512`、墨青 `#1B2420`、舊紙 `#E8DFC8`、淡紙 `#F3ECD9`、朱砂 `#B74732`、青玉 `#6F9C87`。
- 字體：標題使用系統明體序列 `I.Ming, PMingLiU, Noto Serif TC, serif`；正文使用 `Noto Sans TC, Microsoft JhengHei, sans-serif`；數值使用等寬序列。
- 版面：桌機為「狀態窄欄／案卷主文／線索窄欄」，手機收束為單欄與底部五項導覽。
- 招牌元素：主敘事面板像一份被朱砂批註的調查案卷；章節與線索以直排小印記點題，不使用仿古裝飾堆疊。
- 動態：僅在換場時做 180ms 淡入與紙張位移；減少動態偏好時完全停用。
- 無障礙：正文至少 16px、行高 1.75；觸控目標至少 44px；所有狀態有文字與數值；鍵盤焦點使用高對比雙環。
